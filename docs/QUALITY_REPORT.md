# 本地设计质量报告

在「检查 → 本地设计质量」选择所选图层（含子层）、当前画板或所有画板，按当前预览运行。可选 +30% 文字模拟。按类别和「需复核 / 可优化」筛选，展开证据或点击条目定位图层。组件内部图层会定位到持久化实例，报告单独标注源 ID。已过期的结果不能导出或用于定位。

| 规则 | 证据和边界 |
| --- | --- |
| QG01 嵌套圆角 | 只比较实际绘制、四边近似等距、圆角与边框均匀的容器。按外圆角减实测内缩距离给出建议；不规则与有意对比不当作错误。 |
| QG05 图层超出边界 | 复用浏览器实测，区分超出父级还是画板。 |
| QG06 同级图层重叠 | 显示交叠面积，供人工判断。 |
| QT01 小字号 | 读取节点或可见富文本段的实际字号；12 CSS px 为复核参考。 |
| QT02 / QT05 文字裁切 / 溢出 | 复用浏览器文本范围与只读输入的 Canvas 字宽估算，可分别查看原稿和文字模拟结果。 |
| QC02 控件配色 | 仅检查纯文本按钮自身的不透明填充与不透明前景，跳过透明合成、文本分段、禁用控件和文本已超出自身盒子的情况。对比度只反映这组颜色，不包含遮挡。 |
| QI01 控件尺寸 | 使用实际 CSS 尺寸，参考 44×44；跳过禁用控件，不作 WCAG 认证。 |

输出 `designforge.quality-report` v1 JSON。报告以 `baseHash` 绑定项目快照，`context` 记录范围、真实选区 ID、主题、当前画板预览宽度、强制状态、界面语言和模拟场景；`coverage` 记录实际测量宽度及 measured / partial / unavailable。每个 finding 包含稳定规则 ID、类别、严重度、证据性质、画板 ID、实例或普通图层 ID、可选源 ID、模拟场景与证据。报告最多 240 条；单画板 DOM 预算或条数超出时明确记录，不把无结果解释为通过。重复证据按画板、规则、场景、实例/源 ID 合并。原有静态审计和导出保持原口径，不混入新报告。

当前切片不主动矩阵切换断点、主题或状态，不识别真实回退字形，不检查同语义角色的一致性，不修改 Token、样式或结构。仅记录当前编辑器界面语言，并不判断设计稿语言。模拟扩展现有字素，不执行翻译。缺失证据应人工复核。没有模型请求、自动应用或新增 Patch 操作。
