# 已知问题与能力边界

本版是 M1 编辑器核心预览，不宣称完成 M1/M2/M3 全部目标。

## M1 待完成

- 富文本分段样式、可调行高/字体及浏览器文字溢出/裁切提示已在 alpha.4 接入；文字基线工具尚未实现。文字膨胀预检在离屏副本做约30%的字素重复，不是实际翻译或全语言验证。
- 已支持单选图层尺寸拖拽及矩形框选。自由布局有 8 个方向；Flow 子项和断点覆盖仅开放右/下/右下三个方向，防止隐式修改全局位置。标尺/用户参考线已在 alpha.3 接入；同父级基础样式多选缩放已接入；旋转仍未实现。
- 组合与对齐要求同父的自由布局节点；Auto Layout 使用父容器属性/子图层顺序。跨父多选拖动仅移动与当前锚点同父的自由图层。组合、解组和对齐使用实测几何；约束会重新参考新父级。测量下组合/解组会把根层 Fill/Hug 归一化为当前 fixed 尺寸并保留后代布局；含 w/h/sizing/hidden 响应式覆盖等无法无损表示的情况会明确拒绝。
- 父容器切换保留父相对坐标，因此可能改变视觉位置；尚无画布拖入容器和自动坐标换算。
- autoHeight 只在单个容器根的画板生效。多个根元素会回退到固定高度；高度仅改变最小尺寸，不是分页导出。
- Fill/Hug 的循环约束、嵌套百分比尺寸、跨轴最小/最大尺寸尚无设计工具级求解器，采用浏览器 CSS 语义。复杂配置应使用浏览器复核。
- 响应式面板已支持新增/改宽/删除、修改范围选择及逐字段恢复继承；画板宽度预览不写入项目。本节点的可视化范围条、当前预览游标和任意受支持宽度输入已在 alpha.5 接入；整页断点聚合已在alpha.6接入，包括实例源、搜索和来源定位。文字内容、位置和树结构始终是全局属性，不在 maxWidth 覆盖内。
- 组件库为当前项目内定义；alpha.7提供组件/变体管理和“创建源副本→更新此变体”；通用“用当前容器更新变体”入口保留。实例文字可在 Inspector 覆盖，样式覆盖有数据/Patch 接口；源后代的文字、白名单样式和字体已提供可视化覆盖与单字段恢复；根样式使用实例自身属性，文字覆盖面板仍限源后代。定义内不能嵌套实例。
- 从不同源容器新增的变体可能有不同 source ID；已有覆盖在目标变体不存在时会被校验拒绝，应显式调整覆盖后切换，不能静默丢掉用户文字。
- Token 是扁平的颜色/数字及字体方案，不是完整 DTCG 类型层级。支持本地设计系统包跨项目复用，尚无在线库版本同步。新增 Token 入口可输入已有键以修改值。
- 图片保留纵横比（contain），没有裁切、蒙版和矢量路径编辑。SVG 白名单刻意不支持 CSS、文字节点、滤镜、外链、脚本；无法导入的 SVG 需先由用户转换为静态图片。字体检查签名，实际字体解码须浏览器完成。
- 内嵌资源限制单个 base64 data URL 512 KB、合计 1 MB；旧快照还受总大小限制。清理浏览器站点数据仍会丢失本地存档，须定期导出 JSON。Quota 错误不等于保存成功。最近一份未通过校验的原始存档单独保留，点击恢复可先下载修复；若保留失败则不会覆盖当前存档。M0 曾接受但不渲染的非法样式/未知 CSS 字段现在会被明确拒绝，不会自动删字段来通过。
- 编辑器主要面向桌面宽度 ≥1024px；更窄布局会收起部分侧栏。触控绘制、移动浏览器编辑未验收。

## 质量与交付

- Chromium 断言覆盖代表性例子和动作，不保证任意输入项目都无溢出。已加入 Studio 390/768/1440px 的横向及纵向边界检查；其他示例目前主要验证页面横向边界和截图。
- 静态审计不计算完整 Flex/Grid 几何；可主动运行当前浏览器的实际几何检查，但不执行完整 WCAG 审计；alpha 通道合成、遮挡背景和复杂文本实际对比度未完整覆盖。
- 截图供人工复核；已有通用 DOM 盒子碰撞、溢出和文字裁切提示；alpha.6加入Chrome/Linux像素基准和Firefox/WebKit测试矩阵；具体通过范围见VALIDATION.md。AI视觉审查、原生Safari、真实iOS/Android设备未验证。
- 静态 HTML/CSS/ZIP 导出已保留，不包含 React/Vue 组件、真实页面导航或交互状态机。HUD 示例表达布局，不是可玩的游戏。
- 编辑器中的原生 prompt/confirm 仍在使用；人工补丁审批是摘要，不是并排图形 Diff。模型调用、截图/HTML 导入重构、三方冲突合并属于 M2。

## 本轮已修复

- 树子节点在旧根层查询中无法定位的问题，子树复制 ID 冲突、删除后代批注悬空。
- 窄屏导出仍固定画板高度导致底部内容被截断；添加自动高度和纵向断言。
- 暗色 Inspector 文本对比度过低、画板内容撑开后缩放适应范围错误。
- 初次打开示例尚未写入存档；现在首次加载即保存。
- CLI 声称不覆盖但此前允许覆盖输出路径；现在原文件、既存文件和符号链接均拒绝。
- 静态审计此前跳过 Auto Layout 子项的全部检查；现在仅跳过无法可靠静态推算的几何部分。

## M1 alpha.2 新增与修复

- 尺寸拖拽在 DOM 预览，松手才提交；Esc、指针取消和窗口失焦回滚。模型保留参考尺寸约束，不直接丢掉 Stretch/Scale/End/Center。
- 框选仅在当前画板中选取完全包围的可见、未锁定图层，父容器被包围时不重复选其子层；Shift 增选，Esc 恢复框选前选区。Space/H/中键仍可平移。
- 多个断点从宽到窄按字段合并，窄断点继承较宽断点的未覆盖字段。父布局变化同步重算子层定位；hidden=false、透明填充和无描边可正确覆盖基础样式。
- 同一图层不允许重复 maxWidth；允许合法的部分 layout/style/sizing 覆盖，不强制复制整份布局。
- 当前未对任意 Flex/Hug 循环约束做求解；尺寸拖拽会把实际调整的轴切换为 fixed，未调整的轴保持原模式。比例/中心缩放属于交互操作，普通 H5 导出仍为结构化 CSS 约束。

- 容器空白处默认框选，单击可选中容器，已选中的容器可直接拖动。切换/导入项目清除临时预览和修改范围，即使节点 ID 相同也不串用前一个工程的状态。
- 补齐了“清除断点”“新增容器”“双击改字”的祖先锁定校验。输入框内 Ctrl/Cmd+Z 使用原生文字撤销，不触发项目历史回退。

- 修复响应式父宽度覆盖时隐式约束参考尺寸漂移，以及 Flex 行/列切换遗留的 flex-grow。收敛无关断点造成的 CSS 规则膨胀，并保留输出大小回归断言。


## M1 alpha.3 范围

标尺/参考线已接入，坐标相对当前画板；只有当前画板显示辅助线。Shift+R 隐藏标尺与线时停止参考线吸附。参考线支持移动吸附，尺寸拖拽仍为网格吸附；不支持旋转线、参考线集合或整体移动一组线。单选参考线的方向键沿其轴移动 1px，Shift 为 10px。Guide 元数据仅用于编辑器，不自动转成布局约束或导出线条。

自由图层移动现保留约束，并使用实际几何吸附；当时未实现的 Auto Layout 可视化拖动重排已在 alpha.5 接入；跨父级拖放和拖动自动滚屏仍未实现。多选移动仍限同父级可编辑根选区。alpha.6接入Firefox/WebKit矩阵；真机仍未验收。

等距分布支持至少三个同父级、可见且未锁定的自由图层；不会跨父级或覆盖 Auto Layout。固定两端且总宽度超出跨度时会出现负间隙（重叠），并非自动排版修复。只分布图层盒子，不分析其中的可见内容边缘。


## M1 alpha.4 范围

- 多选缩放只调整同父级自由图层盒子及相互间隙，不缩放字体字形或强行改写后代布局。Flow、选中断点覆盖、锁定/不可见、跨父级或超大选区明确拒绝；同父级基础样式在窄预览中可保留约束反解。边缘手柄只转换所改轴为 fixed。
- 富文本支持 text/button/pill 的受限分段，不是 HTML 编辑器；原生 input 和图片替代文字保留纯文本。普通输入按一次中段替换保留前后格式，复杂跨段编辑仍应复核；未实现内嵌超链接、列表/段落样式、文字基线或全文字排版引擎。
- 浏览器检测是当前字体解码和排版结果的只读测量。矩形碰撞可能是有意叠放，包含型背景/容器/图标/线被排除；不处理任意遮挡、蒙版、旋转或所有脚本文字。报告编辑后过期，不能用旧结果证明新设计通过。
- 本地设计系统包严格校验并原子导入，不含画板/评论。默认冲突拒绝；前缀隔离不改当前设计，但新增定义受项目既有数量/资源上限约束。尚无在线订阅、协作合并、嵌套组件依赖图或完整 DTCG 交换。

项目导入在读取前限 8 MB，Patch 限 1 MB，本地库限 2 MB。投影预算每画板 5000、全项目 20000 渲染单位（节点/富文本 span），全项目投影文字最多 200 万字符；过限明确拒绝，CLI/直接渲染也受结构投影预算保护。它不是大型工程性能保证。

文字膨胀按每个文本分段的字素数量向上取整，短段可能超过30%，报告包含该压力场景原有问题，不是与原稿新增差异。复制前限制2000图层、20000元素、200000文本字符；超限返回AUDIT_LIMIT而不克隆。CLI同步使用8MB项目/1MB补丁有界读取，init排他创建。


## M1 alpha.5 范围与评审修复

- Auto Layout 拖动排序限单选、同父级的真实图层或整个实例，支持 Flex 行/列/换行及 Grid。拖动时保留原布局占位、显示半透明图层和插入线；不做跨容器拖放、自动滚屏或多选重排。容器需要先选中再拖动。
- 顺序属于全局结构，不因选中断点而局部化；不改 x/y、尺寸模式、约束、隐藏状态或组件定义。Esc/指针取消/失焦/拖出父容器均取消；同顺序释放和边界键盘操作不增加历史。排序会自然改变兄弟布局位置，锁定仍限制被修改节点和祖先。
- 断点范围条只显示当前持久化节点的最多 8 个覆盖，不汇总父级或组件源的断点。图示按 280–2400px 比例显示；点击分段切换修改范围并预览，独立宽度输入保留明确选择的修改范围。maxWidth=2400 时预览域内没有“基础专属”区间，仍可从原范围下拉选择基础编辑。
- 修正 End 约束与 Hug/Fill 实际尺寸不一致时移动/微调/对齐的跳位，反解使用当前断点尺寸和逐层实测盒子。自由拖动仍会将锚点取整到 CSS px，松手后保持预览几何。
- 图标 SVG 改用 currentColor，断点颜色、主题 Token 和实例覆盖在工作台与静态导出共用同一渲染路径。


## M1 alpha.6 能力边界

- 节点历史仍依赖当前会话的完整快照，最多35份（含当前，至多34步撤销），合计序列化字符上限12MiB，可能更早裁剪。文件导入和刷新不保留该时间线；顶部备份恢复与此不同。列表最多显示最近500个当前/历史节点。不是长期协作日志或Git历史。
- Token、主题和组件源改变不等于引用节点自身字段改变，需使用整体Undo；父容器排序历史在父节点查看。responsive数组按整体比较，复杂子树结构按完整受保护单元比较；任一后来内容变化会阻止该单元回退。不会自动合并冲突、解锁、恢复缺失库定义或改写新ID。可只选择其他安全字段撤回。
- 全页断点统计的是定义和条件，不证明对应图层当前可见。源覆盖被实例属性剔除时可列为空覆盖。定位源条目选中整个实例；alpha.7已接入普通源副本的编辑及显式更新；独立主定义编辑视图、嵌套实例和跨项目在线库仍未实现。
- 三引擎均运行在Linux CI；WebKit并非Safari应用或iOS设备。触屏手势、平台字体解码和真实设备仍需单独验收。像素基准仅Chrome/Linux的5个固定视图；缺图/变化需人工审阅，不能代表所有设计审美与完整WCAG。
- 鼠标事件在Firefox/WebKit可能只提供整数屏幕坐标；小于100%缩放时，一个屏幕像素对应超过1px画板距离，参考线应以实际事件投影为准，精确坐标可用数值面板。真实坐标字段微调已通过增量计算避免累积漂移。


## M1 alpha.7 能力边界

- 源副本是普通持久化画板，不是独立组件编辑模式；随JSON/HTML/ZIP导出，更新源后仍保留，需用户按需删除。源根身份核对防止误把子层提交为整份定义；尚无来源版本三方合并或更新前视觉审批。替换会破坏现有实例覆盖时拒绝，不静默删覆盖。
- 组件/变体重命名限新输入1–200字符；复制沿用源ID作用域。当前支持有限变体列表，不含Figma式多属性变体矩阵或嵌套实例依赖图。主源变化用整体Undo，不计为所有实例的单节点字段修订。
- 实测读数是当前选中主图层的border box，不是多选联合包围盒，也不解释字体实际字形边界或设计美感；隐藏节点不产生虚假零尺寸。基础/断点输入和实际预览仍可不同，输入只改变当前编辑范围。
- 新增工作台指定文字的明暗模式计算对比度检查，不代表整站完整WCAG审计；禁用控件、画板设计内容和透明叠色等仍需分别检查。像素基准只更新两张经查看的工作台PNG，三个Studio导出基准继续保留。
- 完整历史值按需显示；报告包含该变更涉及的完整内容/子树，用户在本地下载后自行决定是否分享。它不能作为Patch导入，展开和导出不写项目或新增撤销步骤。

WebKit属性下拉文字裁切已在alpha.7最终复核修复；统一绘制的控件仍是原生select语义。字体/平台差异继续存在，Chrome像素基准不跨引擎当作相同画面要求。
