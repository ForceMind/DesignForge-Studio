# 已知问题与能力边界

本版是 M1 编辑器核心预览，不宣称完成 M1/M2/M3 全部目标。

## M1 待完成

- 富文本分段样式、文字基线/自动行高控制、长文本碰撞和国际化膨胀分析尚未实现。
- 已支持单选图层尺寸拖拽及矩形框选。自由布局有 8 个方向；Flow 子项和断点覆盖仅开放右/下/右下三个方向，防止隐式修改全局位置。标尺/用户参考线已在 alpha.3 接入；旋转、多选整体缩放仍未实现。
- 组合与对齐要求同父的自由布局节点；Auto Layout 使用父容器属性/子图层顺序。跨父多选拖动仅移动与当前锚点同父的自由图层。组合边界使用设计参考坐标，含复杂 Fill/Hug/约束的分组尚未做通用视觉归一化，应在当前尺寸复核。
- 父容器切换保留父相对坐标，因此可能改变视觉位置；尚无画布拖入容器和自动坐标换算。
- autoHeight 只在单个容器根的画板生效。多个根元素会回退到固定高度；高度仅改变最小尺寸，不是分页导出。
- Fill/Hug 的循环约束、嵌套百分比尺寸、跨轴最小/最大尺寸尚无设计工具级求解器，采用浏览器 CSS 语义。复杂配置应使用浏览器复核。
- 响应式面板已支持新增/改宽/删除、修改范围选择及逐字段恢复继承；画板宽度预览不写入项目。断点可视化范围条、整页断点总览仍待完成。文字内容、位置和树结构始终是全局属性，不在 maxWidth 覆盖内。
- 组件库为当前项目内定义；源容器的修改须点击“用当前容器更新变体”。实例文字可在 Inspector 覆盖，样式覆盖有数据/Patch 接口；完整可视化组件属性编辑尚未完成。定义内不能嵌套实例。
- 从不同源容器新增的变体可能有不同 source ID；已有覆盖在目标变体不存在时会被校验拒绝，应显式调整覆盖后切换，不能静默丢掉用户文字。
- Token 是扁平的颜色/数字及字体方案，不是完整 DTCG 类型层级、跨库版本体系。新增 Token 入口可输入已有键以修改值。
- 图片保留纵横比（contain），没有裁切、蒙版和矢量路径编辑。SVG 白名单刻意不支持 CSS、文字节点、滤镜、外链、脚本；无法导入的 SVG 需先由用户转换为静态图片。字体检查签名，实际字体解码须浏览器完成。
- 内嵌资源限制单个 base64 data URL 512 KB、合计 1 MB；旧快照还受总大小限制。清理浏览器站点数据仍会丢失本地存档，须定期导出 JSON。Quota 错误不等于保存成功。最近一份未通过校验的原始存档单独保留，点击恢复可先下载修复；若保留失败则不会覆盖当前存档。M0 曾接受但不渲染的非法样式/未知 CSS 字段现在会被明确拒绝，不会自动删字段来通过。
- 编辑器主要面向桌面宽度 ≥1024px；更窄布局会收起部分侧栏。触控绘制、移动浏览器编辑未验收。

## 质量与交付

- Chromium 断言覆盖代表性例子和动作，不保证任意输入项目都无溢出。已加入 Studio 390/768/1440px 的横向及纵向边界检查；其他示例目前主要验证页面横向边界和截图。
- 静态审计不计算完整 Flex/Grid 几何、不执行完整 WCAG 审计；alpha 通道合成、遮挡背景和复杂文本实际对比度未完整覆盖。
- 截图供人工复核；尚无 golden image 像素回归、通用碰撞/截断检测、AI 视觉审查。Firefox/WebKit、真实 iOS/Android 设备未验证。
- 静态 HTML/CSS/ZIP 导出已保留，不包含 React/Vue 组件、真实页面导航或交互状态机。HUD 示例表达布局，不是可玩的游戏。
- 编辑器中的原生 prompt/confirm 仍在使用；人工补丁审批是摘要，不是并排图形 Diff。模型调用、截图/HTML 导入重构、三方冲突合并属于 M2。

## 本轮已修复

- 树子节点在旧根层查询中无法定位的问题，子树复制 ID 冲突、删除后代批注悬空。
- 窄屏导出仍固定画板高度导致底部内容被截断；添加自动高度和纵向断言。
- 暗色 Inspector 文本对比度过低、画板内容撑开后缩放适应范围错误。
- 初次打开示例尚未写入存档；现在首次加载即保存。
- CLI 声称不覆盖但此前允许覆盖输出路径；现在原文件、既存文件和符号链接均拒绝。
- 静态审计此前跳过 Auto Layout 子项的全部检查；现在仅跳过无法可靠静态推算的几何部分。

## M1 alpha.2 新增与修复

- 尺寸拖拽在 DOM 预览，松手才提交；Esc、指针取消和窗口失焦回滚。模型保留参考尺寸约束，不直接丢掉 Stretch/Scale/End/Center。
- 框选仅在当前画板中选取完全包围的可见、未锁定图层，父容器被包围时不重复选其子层；Shift 增选，Esc 恢复框选前选区。Space/H/中键仍可平移。
- 多个断点从宽到窄按字段合并，窄断点继承较宽断点的未覆盖字段。父布局变化同步重算子层定位；hidden=false、透明填充和无描边可正确覆盖基础样式。
- 同一图层不允许重复 maxWidth；允许合法的部分 layout/style/sizing 覆盖，不强制复制整份布局。
- 当前未对任意 Flex/Hug 循环约束做求解；尺寸拖拽会把实际调整的轴切换为 fixed，未调整的轴保持原模式。比例/中心缩放属于交互操作，普通 H5 导出仍为结构化 CSS 约束。

- 容器空白处默认框选，单击可选中容器，已选中的容器可直接拖动。切换/导入项目清除临时预览和修改范围，即使节点 ID 相同也不串用前一个工程的状态。
- 补齐了“清除断点”“新增容器”“双击改字”的祖先锁定校验。输入框内 Ctrl/Cmd+Z 使用原生文字撤销，不触发项目历史回退。

- 修复响应式父宽度覆盖时隐式约束参考尺寸漂移，以及 Flex 行/列切换遗留的 flex-grow。收敛无关断点造成的 CSS 规则膨胀，并保留输出大小回归断言。


## M1 alpha.3 范围

标尺/参考线已接入，坐标相对当前画板；只有当前画板显示辅助线。Shift+R 隐藏标尺与线时停止参考线吸附。参考线支持移动吸附，尺寸拖拽仍为网格吸附；不支持旋转线、参考线集合或整体移动一组线。单选参考线的方向键沿其轴移动 1px，Shift 为 10px。Guide 元数据仅用于编辑器，不自动转成布局约束或导出线条。

自由图层移动现保留约束，并使用实际几何吸附；未实现 Auto Layout 可视化拖动重排、跨父级拖放和拖动自动滚屏。多选移动仍限同父级可编辑根选区。FireFox/WebKit/真机仍未验收。

等距分布支持至少三个同父级、可见且未锁定的自由图层；不会跨父级或覆盖 Auto Layout。固定两端且总宽度超出跨度时会出现负间隙（重叠），并非自动排版修复。只分布图层盒子，不分析其中的可见内容边缘。
