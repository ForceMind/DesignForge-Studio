# 已知问题与能力边界

本版是 M1 编辑器核心预览，不宣称完成 M1/M2/M3 全部目标。

## M1 待完成

- 富文本分段样式、文字基线/自动行高控制、长文本碰撞和国际化膨胀分析尚未实现。
- 尺寸目前通过属性面板数值编辑；尚无完整拖拽缩放控件、旋转、标尺、用户参考线和矩形框选。多选以 Shift 点击实现。
- 组合与对齐要求同父的自由布局节点；Auto Layout 使用父容器属性/子图层顺序。跨父多选拖动仅移动与当前锚点同父的自由图层。组合边界使用设计参考坐标，含复杂 Fill/Hug/约束的分组尚未做通用视觉归一化，应在当前尺寸复核。
- 父容器切换保留父相对坐标，因此可能改变视觉位置；尚无画布拖入容器和自动坐标换算。
- autoHeight 只在单个容器根的画板生效。多个根元素会回退到固定高度；高度仅改变最小尺寸，不是分页导出。
- Fill/Hug 的循环约束、嵌套百分比尺寸、跨轴最小/最大尺寸尚无设计工具级求解器，采用浏览器 CSS 语义。复杂配置应使用浏览器复核。
- 响应式属性入口目前支持添加布局/宽度断点与清除全部覆盖；精细断点编辑、可视化范围条、每字段恢复继承待完成。
- 组件库为当前项目内定义；源容器的修改须点击“用当前容器更新变体”。实例文字可在 Inspector 覆盖，样式覆盖有数据/Patch 接口；完整可视化组件属性编辑尚未完成。定义内不能嵌套实例。
- 从不同源容器新增的变体可能有不同 source ID；已有覆盖在目标变体不存在时会被校验拒绝，应显式调整覆盖后切换，不能静默丢掉用户文字。
- Token 是扁平的颜色/数字及字体方案，不是完整 DTCG 类型层级、跨库版本体系。新增 Token 入口可输入已有键以修改值。
- 图片保留纵横比（contain），没有裁切、蒙版和矢量路径编辑。SVG 白名单刻意不支持 CSS、文字节点、滤镜、外链、脚本；无法导入的 SVG 需先由用户转换为静态图片。字体检查签名，实际字体解码须浏览器完成。
- 内嵌资源限制单个 base64 data URL 512 KB、合计 1 MB；旧快照还受总大小限制。清理浏览器站点数据仍会丢失本地存档，须定期导出 JSON。Quota 错误不等于保存成功。
- 编辑器主要面向桌面宽度 ≥1024px；更窄布局会收起部分侧栏。触控绘制、移动浏览器编辑未验收。

## 质量与交付

- Chromium 断言覆盖代表性例子和动作，不保证任意输入项目都无溢出。已加入 Studio 390/768/1440px 的横向及纵向边界检查；其他示例目前主要验证页面横向边界和截图。
- 静态审计不计算完整 Flex/Grid 几何、不执行完整 WCAG 审计；alpha 通道合成、遮挡背景和复杂文本实际对比度未完整覆盖。
- 截图供人工复核；尚无 golden image 像素回归、通用碰撞/截断检测、AI 视觉审查。Firefox/WebKit、真实 iOS/Android 设备未验证。
- 静态 HTML/CSS/ZIP 导出已保留，不包含 React/Vue 组件、真实页面导航或交互状态机。HUD 示例表达布局，不是可玩的游戏。
- 编辑器中的原生 prompt/confirm 仍在使用；人工补丁审批是摘要，不是并排图形 Diff。模型调用、截图/HTML 导入重构、三方冲突合并属于 M2。
